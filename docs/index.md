# Passos Mágicos ML - Documentação

Bem-vindo à documentação do projeto de Machine Learning para predição de risco de defasagem escolar da Associação Passos Mágicos.

## Visão Geral

Este projeto implementa um sistema completo de MLOps para identificar estudantes em risco de defasagem escolar, permitindo intervenções pedagógicas proativas.

## Navegação

- [Referência da API](api_reference.md) - Documentação completa dos endpoints
- [Pipeline de ML](pipeline.md) - Detalhes do pipeline de machine learning
- [Deploy](deployment.md) - Guia de implantação em produção

## Quick Start

```bash
# Instalar dependências
make install

# Treinar modelo
make train

# Iniciar API
make run
```

Acesse a documentação interativa em: http://localhost:8000/docs
